# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. **Removed** the menu requirement for using `tpz_menu_base` and replaced it with our own NUI.
2. **Removed** from the `Config.Deliveries` the `MoneyReward` and `CompanyMoneyReward` options, they are no longer supported - all salaries and money rewards will be set directly from the Oil Fields management (the owner of the company).
3. **Removed** from `Config.OilExtractions` the `MoneyReward`, `WithdrawMoneyFromLedgerAccount` and `MaximumWorkerTasks` options, they are no longer supported - all salaries and money rewards will be set directly from the Oil Fields management (the owner of the company). The withdrawal will no longer be through the system but from the company ledger and the maximum worker tasks will also be having no limit, the owner will be paying the workers based on every task they perform for increasing the company's oil capacity (do not afraid, the owner can now disable the workers oil extraction to prevent paying more money until the company requires oil again).
4. **Removed** from `Config.OilExtractions` the `Enabled` option for having an NPC or not, the NPC must exist in the new update for the new features that are implemented.
5. **Removed** from `Config.Business` the `RequiredJob` option for allowing players to work on oil extractions and deliveries with job requirement or not, this system has been replaced with an employees system if its activated through Management NUI.

## How to update?

- You can easily update the modified files by redownloading from the **Cfx.re Portal** and copy-paste on the mentioned directory file paths.
- If new options have been implemented to the configuration file or edited, **DO NOT** copy-paste the new configuration file, otherwise you will get the latest configuration but you will lose all the changes you have made. The proper way updating a configuration file is by finding the new configuration options or the modified ones and do it **manually**.

*Cfx.re Portal **DOES NOT** force-update your configuration file or any files, if it did, you would always lose all the configuration changes you made or would totally break the script, all files are updated or edited manually.*
