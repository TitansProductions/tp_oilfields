# What has been updated?

## Changelog - (Added, Fixed, Removed):
- **Added** a new system for the oil extractions, it used to have a Maximum Tasks from the configuration file but this feature has been modified and the player can now select how many tasks he is willing to do but he will be getting paid based on the finished tasks, that means if he selects to do 10 tasks and 5 will be performed and wants to stop, he will receive money of the 5 performed tasks and not the 10 - the same is for the unrefined oil the company will receive, it will be based on the successful performed tasks. 
- **Added** new dependency `tpz_skillcheck` which is required for the new job (engine tasks) in order to have difficulties based on the engine health (Download from here: https://github.com/TPZ-CORE/tpz_skillcheck)
- **Added** new feature **Engine Tasks** which is a new job required for doing engine tasks to convert an `Unrefined Oil` to `Refined Oil`. In the previous updated, there was no unrefined oil, now it requires the engine tasks to become a refined oil. Also, the engines have water capacity feature support with **TP Farming** by default (You can also implement yours if you have) and a health system which will require from the employees to do engine repairs. The engine repairs have an extra option to require resources for an engine to be repaired (It also has its own NUI for displaying the requires resources).
- **Added** new feature to allow employees to be able to quit the oil fields company through a prompt. This feature also contains its own NUI and does not use `tp_inputs`.
- **Added** new features for the oil bottle selling, it is now having an npc, a pre-setup objects where the npc is located, its own selling prompt and location, its own NUI instead of `tp_inputs`, a speaking dialogue and advanced blips and open / closed hours.
- **Added** server side permission checks for any actions related to the company management for being safe / protected by injection(s) cheating.
- **Added & Modified** the mechanisms of the oil deliveries, added new features and modified existing ones for better experience (Teleport also got removed).
- **Added** a new feature (optional) which allows you to remove the armed Npcs which we all know, those npcs cause trouble.
- **Added** coal capacity feature for the engines (optional), it has its own NUI to add coal capacity and check stored coal capacity.
- **Added** storage feature support with **TP Containers** - the storage will be required for the engine repairs and tasks.
- **Added** an objectloader system to allow objects placement and to modify easily the Oil Fields company at anytime. This system has been added because of new furnitures we have added to support new features for buying oil bottles and starting oil deliveries.
- **Added** 2 new features to oil bottle sales — a toggle allowing owners/employees to enable or disable bottle sales, and a dedicated purchase location where everyone can buy oil bottles instead of using the main office desk.
- **Added** a new option in the config `Config.StartQueryDelay` which is for fixing sql insert errors on servers that their sql is not loaded properly.
- **Added** oil extractions and oil deliveries history records which shows all the required information related to the tasks.
- **Fixed** some notifications that were using the wrong notification type (for example it should be an "error" type, but had "success" instead)
- **Fixed** on oil extractions the created blips for the mission, they were never removed from the system once cancelled or finished.
- **Fixed** several mistakes related to oil extraction job, such as notifications and payments.
- **Fixed** fixed on oil extractions the holding bucket animation when breaking to reload the animation.
- **Fixed** a bug on oil extractions where the given oil on the company was always the same even if someone did 1 or 10 tasks but it shouldve been multiplied based on the tasks.
- **Removed** the menu requirement for using `tpz_menu_base` and replaced it with our own NUI.
- **Removed** from the `Config.Deliveries` the `MoneyReward` and `CompanyMoneyReward` options, they are no longer supported - all salaries and money rewards will be set directly from the Oil Fields management (the owner of the company).
- **Removed** from `Config.OilExtractions` the `MoneyReward`, `WithdrawMoneyFromLedgerAccount` and `MaximumWorkerTasks` options, they are no longer supported - all salaries and money rewards will be set directly from the Oil Fields management (the owner of the company). The withdrawal will no longer be through the system but from the company ledger and the maximum worker tasks will also be having no limit, the owner will be paying the workers based on every task they perform for increasing the company's oil capacity (do not afraid, the owner can now disable the workers oil extraction to prevent paying more money until the company requires oil again).
- **Removed** from `Config.OilExtractions` the `Enabled` option for having an NPC or not, the NPC must exist in the new update for the new features that are implemented.
- **Removed** the `tp_inputs` dependency, it is now having its own NUI instead of using a dependency. 
- **Replaced** on `Config.Business` the `RequiredJob` option for allowing players to work on oil extractions and deliveries with job requirement or not, this system has been replaced with an employees system if its activated through Management NUI. This option now is only for buying the company.
